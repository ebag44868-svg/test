파이썬 채점
정올 문제 자유 실행 이론 모의고사 도움말
엔진 불러오는 중오프라인 확인 중
답은 자동 저장돼요. 시간 제한 없음.

채점 방식

문제마다 예제 입력과 직접 만든 숨은 입력(총 3~10개)으로 실행해서 출력을 정답과 줄 단위로 비교해요. 줄 끝 공백과 마지막 빈 줄은 무시하고, 줄 앞 공백·단어 사이 공백·대소문자는 정확히 비교해요. 정올 실제 채점 데이터는 공개되지 않아서 판정이 100% 같지는 않아요.

‘삼항 연산자 필수’처럼 빨간 배지가 붙은 문제는 출력이 맞아도 그 문법을 쓰지 않으면 ‘조건 위반’이에요.

버튼

  • 채점하기: 모든 테스트 실행. 틀린 테스트를 누르면 정답 출력과 내 출력을 나란히 보여주고 다른 글자를 표시해요. (외장 키보드: ⌘ + Enter)
  • 실행: 입력값 칸의 내용으로 한 번만 실행. 예제 입력이면 정답과도 비교해요.
  • 한 줄씩 보기: 코드가 어떤 순서로 실행되는지, 각 단계에서 변수 값이 어떻게 바뀌는지 한 단계씩 넘겨 볼 수 있어요. 반복문 추적 연습에 좋아요.
  • 중지: 실행이 멈추지 않을 때. 6초가 지나도 안 끝나면 무한 루프로 보고 자동으로 멈추고, 계속 반복되던 줄을 칠해 줘요.

아이패드 입력 팁

  • 코드 칸 위의 ⇥ 키는 공백 4칸 들여쓰기, ⇤는 내어쓰기. 콜론(:)으로 끝나는 줄에서 줄을 바꾸면 자동으로 4칸 들여써요.
  • 둥근 따옴표(“ ”)는 자동으로 곧은 따옴표로 바뀌지만, 설정 → 일반 → 키보드 → 스마트 구두점을 끄면 더 편해요.
  • 코드와 답안은 이 기기 안에만 저장돼요. 홈 화면 앱을 삭제하면 같이 지워져요.

오프라인

오른쪽 위에 오프라인 준비 완료가 보이면 인터넷 없이 모든 기능이 동작해요. 홈 화면에 추가한 앱은 사파리와 저장 공간이 따로라서, 홈 화면 아이콘으로 처음 열 때 한 번은 인터넷이 연결돼 있어야 해요.

오류 사전

실행할 때 나오는 오류와 같은 설명이에요.
